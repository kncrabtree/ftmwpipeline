# Fixture 1512

Real Blackchirp CP-FTMW experiment, checked in at
`examples/blackchirp_data/1512/`.

## Instrument

Same instrument as 2638: downconversion LO / probe **40960 MHz**, **lower
sideband**; digitizer **50 GS/s** (spacing 2e-11 s), **750000** points,
**15 µs** record. AWG chirp sweeps **4895 → 1520 MHz** IF (RF coverage
36065 - 39440 MHz). Analysis band **26500 - 40000 MHz**.

Blackchirp build `v0.1-491-gf11bcbc` (beta). The `fidparams.csv` `sideband`
cell is the canonical string `LowerSideband`.

## Acquisition

- Chirp duration **2 µs**.
- **17860** shots co-averaged (the lowest-SNR fixture; a strong-molecular-FID
  case — its post-chirp floor shows no separable ringdown knee).

## Sample

Not recorded in the experiment metadata (user-held).

## Ground truth

**Available.** The fixture contains vinyl cyanide (CH2=CH-CN, v=0, hyperfine
resolved/partially resolved) plus other species. The vinyl-cyanide catalog
ground truth (115 in-band transitions, predicted frequencies + uncertainties)
is tracked under
[`1512-vinyl-cyanide-truth/`](1512-vinyl-cyanide-truth/README.md). The
validation scores frequency and uncertainty accuracy for lines unambiguously
attributable to vinyl cyanide — not every line in the spectrum.

## Recommended processing

- `start_us = 3.35` (data-derived via `detect-start`; chirp end ~2.68 µs + the
  switch-bounce ringdown margin).
- No zero-padding (`zpf=0`) and `expf_us=None` (unapodized), `trim=(26500, 40000)`. The canonical FT stays raw so Stage 2/5 statistics are not corrupted; Stage 3 peak detection applies its own zero-padding internally.
- Run `calibrate_tau` before peak detection.
