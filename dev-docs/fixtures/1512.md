# Fixture 1512

Real Blackchirp CP-FTMW experiment, checked in at
`examples/blackchirp_data/1512/`.

## Instrument

Same instrument as 2638: downconversion LO / probe **40960 MHz**, **lower
sideband**; digitizer **50 GS/s** (spacing 2e-11 s), **750000** points,
**15 µs** record. AWG chirp sweeps **4895 → 1520 MHz** IF (RF coverage
36065 - 39440 MHz). Analysis band **26500 - 40000 MHz**.

Blackchirp build `v0.1-491-gf11bcbc` (beta). The `fidparams.csv` `sideband`
cell is the canonical string `LowerSideband`.

## Acquisition

- Chirp duration **2 µs**.
- **17860** shots co-averaged (the lowest-SNR fixture; a strong-molecular-FID
  case — its post-chirp floor shows no separable ringdown knee).

## Sample

Not recorded in the experiment metadata (user-held).

## Ground truth

**Available.** The fixture contains vinyl cyanide (CH2=CH-CN, v=0, hyperfine
resolved/partially resolved) plus other species. The vinyl-cyanide catalog
ground truth (115 in-band transitions, predicted frequencies + uncertainties)
is tracked under
[`1512-vinyl-cyanide-truth/`](1512-vinyl-cyanide-truth/README.md). The
validation scores frequency and uncertainty accuracy for lines unambiguously
attributable to vinyl cyanide — not every line in the spectrum.

## Recommended processing

- `start_us = 3.35` (data-derived via `detect-start`; chirp end ~2.68 µs + the
  switch-bounce ringdown margin).
- No zero-padding (`zpf=0`) and `expf_us=None` (unapodized), `trim=(26500, 40000)`. The canonical FT stays raw so Stage 2/5 statistics are not corrupted; Stage 3 peak detection applies its own zero-padding internally.
- Run `calibrate_tau` before peak detection.
- `recommend_shape` returns **lorentzian**; fit Stage 5 with `shape="lorentzian"`.

## Stage 5 validation

Measured with `validate-stage5-shape-error` on the canonical bounded-merge build
(lorentzian, 237 windows, 286 fitted lines; κ=0.05, F=3). This is the **low-SNR**
member of the set — it stresses the noise-dominated regime of the gate.

- **Tier 1 (SNR-aware health):** overall pass **0.93**. The noise-dominated bulk
  (`SNR_max<100`, 225 windows) sits at χ²ᵣ median **1.17** and passes at 0.93 —
  healthy, as expected for a weak fixture (the model deficit is invisible below
  noise, so ε≈0 there). The handful of SNR≥100 windows pass at 0.83–1.0.
- **Tier 3 (ground truth — the sparse, clean accuracy measurement):** matched
  against the 115 vinyl-cyanide v=0 lines (`1512-vinyl-cyanide-truth/lines.csv`).
  Recall **0.37** (42/115) — bounded by detectability, not fit quality: at 17 860
  shots the faint catalog lines are below detection. For the matched lines the
  result is the headline uncertainty finding:
  - **Frequency-accuracy floor** ≈ **9.0 kHz** (detrended residual RMS; raw 16.1
    kHz, after removing a linear-in-`f_RF` drift of 2.3 kHz/GHz + a −84 kHz
    offset). This is an **instrument property** — free-running digitizer clock
    drift — **not a pipeline defect**; Tier 3 reports it, never fails on it.
  - **σ_f honesty:** the reported LSQ σ_f (median **0.18 kHz**) is an honest
    *precision* but the matched residual is **~49×** larger, i.e. σ_f is ~49×
    overconfident *as absolute accuracy*. σ_f ∝ 1/SNR; the accuracy floor is
    constant, so σ_f structurally cannot capture it. This is the precision-vs-
    accuracy gap the 1512/655 ground truth was acquired to characterize.

The sparse, single-species 1512 list gives the **clean** accuracy-floor read; the
dense 655 union is the recall/SNR-range counterpart but its automated match is
noisier (see [`655.md`](655.md)).
